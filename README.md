# Running the Backend
1st step. Navigate to the backend folder by using "cd backed"
2nd step. Install all required dependencies "npm i"
3rd step. npm run dev

#Running the Frontend
1st step. Navigate to the backend folder by using "cd frontend"
2nd step. Install all required dependencies "npm i"
3rd step. npm run dev

P.S.: You should have two terminals running one for the backend and one for the frontend
